# Energy-Monitor-Dashboard
EnergyOS Monitoring Dashboard – Project Overview 
EnergyOS Monitoring Dashboard is a real-time energy management system for campuses or multi-building environments
Provides a centralized view of energy consumption, generation, and system performance
Displays key metrics:
Total energy consumption (kWh)
Current load (live kW)
Peak usage (24-hour max)
Solar generation
System efficiency
CO₂ savings
Includes a real-time alert system for threshold breaches and abnormal usage
Features a live-updating line chart showing:
Grid energy usage
Solar generation
Total consumption trends
Enables pattern analysis to detect peaks, drops, and anomalies in energy usage
Provides navigation for:
Historical data visualization
Building-wise energy comparison
Alerts management
System settings and thresholds
Built with scalability and API integration for real-time data streaming and cloud connectivity
Designed for efficient monitoring, analysis, and optimization of energy usage
